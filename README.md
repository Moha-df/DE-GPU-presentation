# Évolution différentielle sur GPU : présentation

Présentation de soutenance du projet de calcul parallèle (Master IM, UHA) :
du PSO CUDA fourni à trois versions GPU de l'évolution différentielle (DE).

Zainab Elamri, Omar Elsemry, Mohamed De Franceschi.

## Voir la présentation

1. Télécharger le dépôt : bouton vert **Code**, puis **Download ZIP**, et décompresser le dossier.
2. Double-cliquer sur `index.html` : la présentation s'ouvre dans le navigateur (Chrome ou Firefox).
   Pas besoin d'internet ni de serveur, tout est dans le dossier.

## Naviguer

| Touche | Action |
|---|---|
| Flèche droite ou espace | suivant (étape d'animation ou slide suivante) |
| Flèche gauche | précédent |
| F | plein écran (Échap pour sortir) |
| S | vue orateur : notes, chrono et slide suivante dans une 2ᵉ fenêtre |
| Échap ou O | vue d'ensemble des slides |

Sur la slide des temps de calcul, on peut aussi cliquer sur les boutons D = 10, 50 et 100.

## Contenu

- `index.html` : les slides et les notes orateur
- `css/`, `js/` : mise en page et animations
- `vendor/` : reveal.js, GSAP et Chart.js (copies locales)
- `fonts/` : polices Bricolage Grotesque, Figtree et JetBrains Mono (licence SIL OFL)
